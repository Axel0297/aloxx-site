Terminos de Servicio - Aloxx (automatizacion de subida de clips)

Ultima actualizacion: 3 de septiembre de 2026

Esta aplicacion ("Aloxx") es una herramienta personal de automatizacion desarrollada y utilizada exclusivamente por Axel Raies para publicar sus propios clips de streaming (juegos, principalmente League of Legends) en su canal de YouTube y en su cuenta de TikTok.

Uso permitido

Aloxx esta disenada para uso exclusivo de su desarrollador, sobre sus propias cuentas de YouTube y TikTok. No esta disponible publicamente ni ofrecida como servicio a terceros.

Responsabilidad del contenido

El desarrollador es el unico responsable del contenido que la aplicacion publica, ya que todo el contenido (video, titulo, descripcion, miniatura) es creado y aprobado manualmente por el antes de la publicacion automatica.

Uso de las APIs de terceros

Esta aplicacion utiliza la API de datos de YouTube (YouTube Data API v3) y la API de TikTok (Content Posting API) exclusivamente para subir contenido propio del desarrollador a sus propias cuentas, cumpliendo con los Terminos de Servicio de cada plataforma.

Cambios en estos terminos

Estos terminos pueden actualizarse ocasionalmente. La version vigente siempre estara disponible en esta misma direccion.
